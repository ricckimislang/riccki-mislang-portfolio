# Alex Morgan portfolio

This is a Nuxt portfolio site with a homepage, project index, and case study pages.

## Content placeholders

- The résumé action currently points to `#contact` and is labeled “request a copy” until a real `public/resume.pdf` is available. No placeholder PDF is included.
- The portrait is an intentionally labeled CSS holder. No portrait asset is present yet, so the homepage does not reference a made-up image path.
- `https://example.com` and the generic `https://github.com/` values in `data/portfolio.ts` are sample project links. Replace them with real destinations before launch.

Run `npm run dev` for local development, or `npm run generate` to verify the static build.

# Riccki Rejee Mislang portfolio

This is a Nuxt portfolio site with a homepage, project index, and case study pages.

## Content placeholders

- The résumé action opens a request email until a real `public/resume.pdf` is available. No placeholder PDF is included.
- The portrait is an intentionally labeled CSS holder. No portrait asset is present yet, so the homepage does not reference a made-up image path.
- The project and repository entries in `data/portfolio.ts` are sample content. Their external links stay empty until verified destinations are available, so unavailable links are omitted from the UI. Add real destinations before launch.

Run `npm run dev` for local development, or `npm run generate` to verify the static build.
